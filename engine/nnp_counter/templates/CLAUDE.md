# nnp-counter — โฟลเดอร์ข้อมูล

โฟลเดอร์นี้เก็บ **รายงานตัวนับเครื่องถ่ายเอกสารรายเดือน (.xlsx)** ที่สร้างจากอีเมลใน Gmail โดย plugin `nnp-counter`
ตั้งค่าองค์กรไว้ใน `nnp-config.json` (ผู้ส่งอีเมล, โฟลเดอร์, รูปแบบ master)

## คำสั่ง (พิมพ์ในแชท Claude Cowork)
- `/nnp-counter:setup` — ตรวจ/เตรียมระบบ (ทำครั้งแรก)
- `/nnp-counter:add-org` — เพิ่มองค์กร/หน่วยงานใหม่
- `/nnp-counter:run {org} {YYYY-MM}` — ประมวลผล 1 องค์กร 1 เดือน (ใส่ `--dry-run` เพื่อซ้อม)
- `/nnp-counter:all {YYYY-MM}` — ทุกองค์กรพร้อมกัน
- ไม่ระบุเดือน/องค์กร → ระบบจะถามกลับเสมอ

## กฎ
1. ต้องรู้เสมอว่า **องค์กรไหน + เดือนไหน** — ห้ามเดา
2. แก้ไฟล์ .xlsx ผ่านโปรแกรม `.nnp/nnp.pyz` เท่านั้น (`python3 .nnp/nnp.pyz <คำสั่ง> --org <org> --month YYYY-MM`) ห้ามเขียนทับด้วยมือ
3. Gmail: อ่านและติด label เท่านั้น ห้ามส่ง/ลบ/ตอบ
4. ห้ามจบงานก่อน `verify` ผ่าน
5. ไฟล์ master (รายชื่อเครื่อง) ผู้ใช้ดูแลเอง — โปรแกรมไม่แก้

รายละเอียดทั้งหมดอยู่ใน skills ของ plugin `nnp-counter`
