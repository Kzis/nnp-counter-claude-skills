# /nnp-counter-oag {year-month}

สั่งให้ agent **oag** (สตง.) อ่านอีเมลของ **เดือนที่ระบุ** แล้วสร้างไฟล์รายงานเดือนนั้น

## ขั้นตอน (ทำตามลำดับ ห้ามข้าม)

1. **อ่านค่าเดือนจากอาร์กิวเมนต์** — รับรูปแบบ `2026-09`, `2026/09`, `202609`, `09/2026` แล้ว normalize เป็น `YYYY-MM`
   - **ไม่มีเดือน หรืออ่านไม่ออก → ต้องถามกลับเสมอ** ด้วย AskUserQuestion (ห้ามเดา ห้ามใช้เดือนปัจจุบันเอง):
     ตัวเลือก = "เดือนที่แล้ว (YYYY-MM)", "เดือนนี้ (YYYY-MM)", "ระบุเอง"
   - เดือนอยู่ในอนาคต (เลยเดือนปัจจุบัน) → ถามยืนยันก่อน
2. **อ่านตัวเลือก** (ถ้ามี): `--dry-run` (ซ้อมบนสำเนา ไม่แตะไฟล์จริง/ไม่ติด label), `--env test` (label ทดสอบ `zz-test-…`), `--reprocess` (ประมวลซ้ำอีเมลที่ done แล้ว), `--ignore-existing` (ใช้กับ --dry-run เท่านั้น: ซ้อมโดยไม่สนประวัติ/รายงานที่มีอยู่ เพื่อเทียบผลกับของเดิม) — ไม่ได้ขอก็ไม่ใส่
3. **ประกาศให้ผู้ใช้เห็นก่อนเริ่ม**: `ORG=oag (สตง.)  MONTH=YYYY-MM  MODE=REAL|DRY-RUN`
4. **เรียก sub agent** ด้วย Agent tool (subagent_type: general-purpose) โดยใช้ prompt ตามแม่แบบด้านล่าง
5. รับรายงานสรุปจาก agent แล้วรายงานผู้ใช้ (จำนวนแถว, สถานะ, เครื่องที่ยังไม่ส่ง, สิ่งที่ต้องตรวจ, ผล verify)

## แม่แบบ prompt ของ sub agent

```
คุณคือ agent oag (สตง.) ของระบบ nnp-counter
อ่านและทำตาม agents/oag/AGENT.md ในโฟลเดอร์งานทั้งหมด (และ CLAUDE.md)
พารามิเตอร์ที่บังคับ: ORG=oag  MONTH=<YYYY-MM>  OPTIONS=<--dry-run ฯลฯ หรือ none>
รันคำสั่งไฟล์/สคริปต์ด้วย device_bash ที่โฟลเดอร์งานบนเครื่องผู้ใช้ ($HOME/mnt/<ชื่อโฟลเดอร์งาน>, ตรวจด้วย ls ให้เห็น CLAUDE.md)
ห้ามประมวลผลองค์กรอื่นหรือเดือนอื่น ห้ามถามผู้ใช้ — ถ้าติดปัญหาให้หยุดแล้วรายงานสาเหตุ
จบด้วยรายงานสรุปตามรูปแบบใน AGENT.md
```
