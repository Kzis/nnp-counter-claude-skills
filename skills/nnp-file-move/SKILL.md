# ย้าย / สำรองไฟล์

`begin` เรียก `move_misplaced` ให้อัตโนมัติ:
- ไฟล์ที่ชื่อตรงรูปแบบแต่อยู่ผิดโฟลเดอร์ (เช่นรายงานอยู่ใน 02_historys) → ย้ายเข้าที่ถูก ผลอยู่ใน `moved_files`
- ถ้าปลายทางมีไฟล์ชื่อเดียวกันอยู่แล้ว → **ไม่ทับ** รายงานใน `move_conflicts` ให้คนตัดสินใจ
- ไม่มีการลบไฟล์เด็ดขาด (บนเครื่องผู้ใช้ลบไม่ได้โดยไม่ขออนุญาต); ไฟล์ที่ไม่ใช้ให้ย้ายไป `_to_delete/` แล้วบอกผู้ใช้
- ก่อน `apply` รอบจริงที่จะแก้ไฟล์เดิม ระบบสำรองไว้ที่ `_work/backup/<ts>-<org>-<ym>/` (ค่า `backup` ในผลลัพธ์)

เมื่อต้องย้ายเอง ใช้ `mv -n` เท่านั้น แล้วตรวจว่าย้ายจริง
