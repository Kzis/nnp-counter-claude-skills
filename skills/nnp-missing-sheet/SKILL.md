# แท็บ `missing`

เขียนใหม่ทุกครั้งที่ `apply` ในไฟล์รายงานของเดือน
- ตาราง A:D = เครื่องใน master ที่ **ไม่มี** แถวในเดือนนั้น (หัว: unit, machine, building, reportedLastMonth)
- สรุป F1:G4 = ทั้งหมด / ส่งแล้ว / ยังไม่ส่ง / อัปเดตล่าสุด
- สมการต้องจริง: ส่งแล้ว + ยังไม่ส่ง = จำนวนเครื่องใน master (`verify` ตรวจ)
ห้ามแก้ด้วยมือ — รัน `apply` ใหม่แทน
